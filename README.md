# 🔍 AnalyzedCV - Resume Diagnostic Tool

AnalyzedCV is your personal career strategist. It uses semantic parsing and AI-driven insights to analyze how well your resume matches a job description, giving you the edge you need to get noticed. 📈

### ✨ Features

- 🎯 **Match Scoring:** Get an instant compatibility percentage for any job.
- 🚩 **Keyword Gaps:** Discover exactly which skills are missing from your CV.
- 🧠 **Semantic Analysis:** Goes beyond simple words to understand your experience.
- 💡 **Improvement Tips:** Actionable feedback to optimize your professional profile.

### 🛠️ Setup & Installation

1️⃣ **Clone the repo:**

```bash
git clone https://github.com/KedarGhadyalji/AnalyzedCV.git
```

2️⃣ **Install Dependencies:**

```bash
npm install
```

3️⃣ **Launch:**
Execute this command to start analyzing! 🧪

```bash
npm run dev
```
